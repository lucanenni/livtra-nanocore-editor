   If it does not respond
  Check                                                 What to do
  MIDI channel                                          Match controller and device channels. Device channel 0 is Omni.

  ON/OFF value                                          Use 0 for OFF and 127 for ON. Values below 64 are OFF.

  Type value                                            Send the exact Type ID, not a continuously scaled knob value.

  Parameter availability                                Some slots work only with selected effect types; '-' means ignored.

 控制器设置示例与使用帮助
 分配示例
 控制器控件                                        MIDI 分配                用途
 脚钉 1                                         CC20：按下 127，松开 0       按下开启 FX1，松开关闭

 脚钉 2                                         CC21：切换 127 / 0        切换 FX2 开关

 脚钉 3                                         CC82：按下 127，松开 0       下一个预设

 脚钉 4                                         CC80：切换 127 / 0        打开或关闭调音器

 旋钮 1                                         CC60：范围 0-127          音箱增益

 旋钮 2                                         CC89：范围 0-127          混响比例

 选择器                                          CC47：精确数值 0-6          选择混响类型


 没有响应时
 检查                                    处理方法
 MIDI 通道                               确保控制器与设备通道一致；设备通道 0 为全通道接收。

 开关数值                                  关闭用 0，开启用 127；小于 64 表示关闭。

 类型数值                                  发送精确类型 ID，不要使用连续缩放的旋钮数值。

 参数适用性                                 部分参数只适用于特定类型；“-”表示忽略。


  适用范围

  适用于 NanoCore 的标准 MIDI CC 与 Program Change；音箱模型、配置文件及 IR 槽位不在本表中。
